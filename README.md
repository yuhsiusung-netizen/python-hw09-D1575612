## 程式用途與執行方式

本程式整理桌遊體驗與電影欣賞的文字報名名單，移除半形空白並統一小寫，以集合去重與比較兩場名單，再用各場去重人數計算費用。它也會列出共同參加者、各場限定名單、全部參加者、不同人數、報名人次及通知名單預覽。

將 `activity_signup_學號.ipynb` 上傳到 Google Colab 後，從上到下執行各儲存格。三組測試各有完整程式與保留的執行輸出；測試二、三只修改電影原始文字名單。

## 問題回答

**問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？**

整理後的 list 是 `['amy', 'ben', 'amy', 'cora']`，它保留輸入順序，也保留重複報名的 `amy`，所以裡面有 4 筆資料；但同一人同場只算一次，轉成 set 後只剩 `amy`、`ben`、`cora` 三個不同的人，因此桌遊費用是 3 × 120＝360 元。list 保留順序與重複項目；set 去除重複項目，但不保證順序，也不適合用位置索引，因此顯示前會排序。

**問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。**

測試三的兩個去重集合相同，都是 `{'amy', 'ben', 'cora'}`，所以交集和聯集各有 3 人，總不重複人數是 3。人次是兩場分開計數：3＋3＝6 人次，因為每個人都報名了兩場。費用也分場計算，桌遊 3 × 120＝360 元，電影 3 × 80＝240 元，總應收 360＋240＝600 元。
